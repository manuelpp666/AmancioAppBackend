# Alcance del Proyecto - Campus AV Móvil

A continuación se detalla la delimitación de las funcionalidades incluidas en la aplicación móvil y aquellas que permanecen exclusivamente en la versión web:

| Incluido en la aplicación móvil | Excluido (permanece solo en la web) |
| :--- | :--- |
| Acceso con usuario y contraseña, cambio obligatorio de contraseña en el primer ingreso y control por rol. | Todo el módulo de pagos: pensiones, deudas, tarifario, caja y recaudación. |
| Consulta y registro de notas por bimestre, y libreta del estudiante. | Conciliación bancaria BCP, archivos CREP y reportes de cobranza. |
| Registro y consulta de asistencia, con reporte por sección y fechas. | Trámites con costo y solicitudes que generan un pago. |
| Conducta: reportes o partes, catálogo de faltas y nota de conducta por bimestre. | Matrícula y renovación como proceso de gestión, incluida su parte económica. |
| Citas de psicología: solicitud, agenda, historial y seguimiento. | Panel de control administrativo completo: gestión de personal, permisos, estructura académica y configuración de la página web. |
| Cursos: materiales, clases virtuales, tareas y entregas con archivo o foto. | Editor de contenido web, noticias, calendario institucional y chatbot. |
| Horario escolar del estudiante y del docente. | Procesos de admisión, postulantes y programa de verano. |
| Mensajería interna entre los usuarios del campus. | Reportes y exportaciones masivas de uso administrativo. |
| Perfil del usuario y consulta del estado de matrícula del año, sin información económica. | |
| Notificaciones push, caché local y modo offline. | |
